# Security Policy

## Supported Versions

Currently, the following versions of the project are being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| 0.x.x   | :x:                |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, please report them to the maintainers privately via email. You can find the contact email in the most recent commits. 

We take all security vulnerabilities seriously and will aim to resolve them quickly. When reporting a vulnerability, please provide:
* A summary of the vulnerability.
* Steps to reproduce the issue.
* Any known mitigations.

You should receive a response within 48 hours. If the issue is confirmed, we will release a patch as soon as possible and credit you for the discovery.
